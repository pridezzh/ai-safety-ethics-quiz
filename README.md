## 使用

- 多个关键词用空格分隔，表示同时包含；按 `/` 聚焦搜索，按 `Esc` 清空。
- 开启自测模式后，点击“参考答案”展开；点击配图可放大。
- 地址栏链接保留当前搜索与筛选条件，可复制分享。
- 下载 `index.html` 后用浏览器打开，即可离线检索和查看配图，无需安装依赖。
